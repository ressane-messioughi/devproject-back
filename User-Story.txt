Plateforme collaborative de gestion de projet de développement
_______________________________________

En tant que "Visiteur" je peux Accéder à la page [Home,Connexion,Inscription] /// AUTH
En tant que "Visiteur" je peux me Connecter via le formulaire de connexion ou m'inscrire via le formulaire d'inscription /// AUTH
__________________________________

En tant que "User" je peux Gérer mon profil /// USER - USER 
En tant que "User" je peux Voir touts les projets /// PROJECT - USER
En tant que "User" je peux Voir touts les projets que j'ai créer PROJECT - OWNER


En tant que "User" je peux Rejoindre un projet /// PROJECT - USER
En tant que "User" je peux Créer un projet     /// PROJECT - USER 
__________________________________

En tant que "UserInProject" je peux Consulter les membre de mon équipe /// TEAMS - USER
En tant que "UserInProject" je peux Consulter le Sprint Planning /// SPRINT - USER
En tant que "UserInProject" je peux Accéder aux répertoires GitHub assigné au projet /// GITHUB - USER
En tant que "UserInProject" je peux Accéder aux fichiers BUG/DEBUG issue du même projet /// BUG - USER
En tant que "UserInProject" je peux Upload et Download des fichiers dans la rubrique BUG/DEBUG /// BUG - USER
En tant que "UserInProject" je peux Accéder aux Journal du projet et rédiger un message  /// Journal - USER
En tant que "UserInProject" je peux Consulter les task attribué à chaque membre de l'équipe par le [OwnerProject] /// Task - USER
En tant que "UserInProject" je peux Accéder et Consulter ainsi que Download les différents Shémas (UML, modélisation...) ///Shémas - USER

__________________________________

En tant que "OwnerProject" je peux Ajouter ou Supprimer des membres dans l'équipe /// TEAMS - OWNER
En tant que "OwnerProject" je peux Reset le Sprint Planning /// SPRINT - OWNER
En tant que "OwnerProject" je peux Ajouter ou modifier le ou les URL GitHub /// GITHUB - OWNER
En tant que "OwnerProject" je peux Supprimer d'eventuel bug résolus /// BUG - OWNER
En tant que "OwnerProject" je peux Supprimer des messages dans le Journal /// JOURNAL - OWNER
En tant que "OwnerProject" je peux Upload ou Supprimer les Shémas /// SHÉMAS - OWNER 
En tant que "OwnerProject" je peux Assigné differentes taches aux differents membre de mon équipe /// TASK - OWNER 
__________________________________

En tant que "ADMIN" je peux Consulté la liste des Utilisateurs global et voir leurs données (Teams, Project, etc ...) /// ADMIN - OWNER
En tant que "ADMIN" je peux Consulté la liste des Projects et voir les données nécessaire (Nmbre de membre, créer depuis etc ...) /// ADMIN - OWNER
En tant que "ADMIN" je peux Consulté la liste des Teams et voir les donnée nécessaire (Nmbre de membre, créer depuis etc ...) /// ADMIN - OWNER
